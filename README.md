# Spectator Higgs Dynamics During Kination

This repository contains codes to study the dynamics of a spectator Higgs field non-minimally coupled to gravity during a kination era. The analysis includes the effects of a dimension-six operator in the scalar potential,

\[
V(h)\approx\xi R h^2+\frac{\lambda}{4}h^4+\frac{g^2}{6\Lambda^2}h^6.
\]

The code "parameter_scan" allows to study the parameter space, the different scenarios the potential leads to in each region and other physical quantities. The code "lattice_analysis" requires files obtained from simulations of the code CosmoLattice, implementing the previous model. It allows to analyze the dynamics from the simulations, displaying plots of energies, spectra, histograms and computing other cosmological quantities such as reheating temperatures.
